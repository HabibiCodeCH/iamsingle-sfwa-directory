SFWA Resources

Tools and building blocks for single-file web apps — things this directory relies on, or that make building one easier.

safe-markdown

A minimal markdown renderer that outputs real DOM nodes, never an HTML string — no innerHTML anywhere in the call path, so there's no injection sink to sanitise. Built for rendering markdown you don't fully trust — comments, bios, LLM output — inside a single-file app, where pulling in a full parser plus a separate sanitiser is a lot of weight for one HTML file. Zero dependencies, about 4.8 KB gzipped.
