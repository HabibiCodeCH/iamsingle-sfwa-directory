The badge will only be updated if the app passes our automated checks, here is what will happen:

  1. You paste the commit or pull request where the fix landed.
  2. We look it up on GitHub, check it belongs to this entry’s repo, and read who wrote it. No need to tell us your handle, the commit already says.
  3. A request opens on this directory with that author added as co-author, so the credit lands on their GitHub profile.
  4. An automated check re-loads the app and records every file it pulls in. If it pulls in nothing, the badge becomes certified sfwa and the fixer is credited on the entry, with the date.
A commit URL, a PR URL, or just the commit sha. This is what proves the fix is real, and who made it.
